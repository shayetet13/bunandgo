⚠ ตรวจพบความพยายามเข้าถึงระบบโดยไม่ได้รับอนุญาต

ระบบรักษาความปลอดภัยของเว็บไซต์นี้ตรวจพบว่าที่อยู่ IP ของท่านพยายามเข้าถึงเส้นทางที่ไม่มีอยู่จริง ซึ่งตรงกับรูปแบบที่ใช้ในการสแกนช่องโหว่หรือพยายามเจาะระบบ (unauthorized access / vulnerability scanning) การเข้าถึงครั้งนี้ถูกบันทึกไว้แล้วโดยอัตโนมัติ

ข้อกฎหมายที่เกี่ยวข้อง

การกระทำในลักษณะนี้เข้าข่ายความผิดตามพระราชบัญญัติว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ พ.ศ. 2550 และที่แก้ไขเพิ่มเติม (ฉบับที่ 2) พ.ศ. 2560 มาตรา 5 และมาตรา 7 (เข้าถึงระบบหรือข้อมูลคอมพิวเตอร์ที่มีมาตรการป้องกันโดยมิชอบ) รวมถึงมาตราอื่นที่เกี่ยวข้อง ซึ่งมีโทษทั้งจำคุกและปรับ

ข้อมูลการเข้าถึงของท่าน ได้แก่ หมายเลข IP เวลา และตำแหน่งโดยประมาณ จะถูกรวบรวมและรายงานไปยังหน่วยงานดังนี้

  • กระทรวงดิจิทัลเพื่อเศรษฐกิจและสังคม (MDES)
  • กองบัญชาการตำรวจสืบสวนสอบสวนอาชญากรรมทางเทคโนโลยี (บช.สอท. / CCIB)
